# Samuel S. S. Neto — Portfólio

Portfólio pessoal estático, publicado no GitHub Pages.

## Estrutura

- `index.html`: página inicial do portfólio.
- `pages/`: páginas de detalhes de competências, formação, projetos, qualificações e stacks.
- `assets/css/`: estilos compartilhados das páginas de detalhes.
- `assets/img/img.svg/`: ícones SVG usados no site.

## Visualização

Abra `index.html` no navegador ou publique o repositório no GitHub Pages. O projeto não requer etapa de build.
